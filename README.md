# dom5

Modul s paketom [`vreme`](vreme) za delo z vremenskimi postajami in ukazom `dom5`,
ki paket uporablja prek ukaznega vmesnika ([urfave/cli/v3](https://github.com/urfave/cli)).

```
go get github.com/nemke357x/dom5@v1.0.0
go run github.com/nemke357x/dom5@v1.0.0 --minTemp -10 --maxTemp 45 --stMeritev 2
```

Stikala: `--minTemp` (privzeto -50), `--maxTemp` (privzeto 50), `--stMeritev` (privzeto 3).
